# Sidequest

Sidequest is a local-first project memory layer for software projects.

## Development

Prerequisites are Node.js 24, pnpm 11, Rust 1.98.0, and the macOS Xcode toolchain.

```bash
pnpm install
pnpm desktop
```

Run the local baseline with the commands defined in [`package.json`](./package.json) and the release gate in [`docs/delivery/acceptance.md`](./docs/delivery/acceptance.md).

Product and architecture documentation starts at [`docs/README.md`](./docs/README.md).
